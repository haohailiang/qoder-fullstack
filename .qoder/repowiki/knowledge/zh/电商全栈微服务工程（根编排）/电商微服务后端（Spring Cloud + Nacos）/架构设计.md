Maven 多模块聚合工程（`pom.xml` 为父 POM，packaging=pom），按业务域拆分为五个子模块：
- `ecommerce-common`：纯公共依赖，定义统一响应体 `Result<T>`、全局异常处理 `GlobalExceptionHandler`、业务异常 `BusinessException` 以及跨服务消息体 `SeckillMessage`。
- `ecommerce-gateway`：基于 Spring Cloud Gateway 的无状态网关，通过 `AuthGlobalFilter` 在入口处校验 JWT（HS256），白名单放行登录/注册/验证码/健康检查/Swagger，并将解析出的 `X-User-Id`、`X-User-Name` 注入下游请求头。
- `ecommerce-user`：用户认证与短信验证码服务，使用 Spring Security + JJWT 签发/验证 Token，Redis 做会话存储，含完整的 controller/service/repository/entity 分层及单元测试。
- `ecommerce-product`：商品与库存服务，集成 Elasticsearch（`ProductDocument` + `ProductElasticsearchRepository`）做商品检索，使用 Redis + Lua 脚本（`lua/seckill_stock.lua`）实现原子预扣减库存。
- `ecommerce-order`：订单服务，通过 Feign `ProductClient` 调用商品服务，监听 RabbitMQ 队列 `SECKILL_QUEUE` 异步创建订单。

依赖方向：gateway → user/product/order；order → product（Feign）；user/product/order 均依赖 common。各业务服务通过 `bootstrap.yml` + Nacos 进行配置发现，数据库初始化 SQL 放在各自 `resources/db/schema.sql`，MyBatis Mapper XML 位于 `resources/mapper/`。每个服务均有独立 Dockerfile（`Dockerfile.user|product|order|gateway`），采用 Maven multi-stage 构建。
