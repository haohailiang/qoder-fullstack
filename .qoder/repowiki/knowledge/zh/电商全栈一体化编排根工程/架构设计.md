根目录作为编排层而非业务代码层：docker-compose.yml 同时声明基础设施（mysql、redis、nacos、elasticsearch、rabbitmq）与应用容器（ecommerce-gateway/user/product/order + frontend-base/product-app/order-app），通过 compose network 共享 DNS 主机名；init-sql/01-init-database.sql 挂载到 /docker-entrypoint-initdb.d 由 MySQL 镜像在首次启动时自动执行；vm-ssh.js 提供基于 ssh2 的远端 VM 部署辅助脚本，独立于 compose 运行。backend 与 frontend 之间无直接代码耦合，仅通过网关端口（8080）与 nginx 反向代理进行 HTTP 通信。
