### DemoDataInitializer
- 定义：用户服务中的演示数据初始化类，用于在应用启动时向数据库插入 admin、zhangsan、lisi 三个默认用户（密码均为 123456）以及 6 个商品（含 3 个秒杀商品）。

### TrustedAuthenticationFilter
- 定义：业务微服务侧的过滤器，读取网关 `AuthGlobalFilter` 注入的 `X-User-Id` / `X-User-Name` 请求头，将用户信息放入 SecurityContext，使下游服务无需重复校验 JWT。
- 别名：信任认证过滤器

### 秒杀
- 定义：高并发抢购场景：商品服务通过 Redis Lua 脚本原子预扣库存，成功后发送 `SeckillMessage` 到 RabbitMQ，订单服务异步消费创建订单；同时通过 Redis 记录用户已购买标识防止重复购买。
- 别名：seckill、抢购

### 两步验证
- 定义：登录/注册采用的串行验证流程：先提交图片验证码（Base64 PNG + captchaKey），通过后才能获取短信验证码；最终请求体同时携带 `captchaKey`、`captchaValue` 与 `smsCode`，后端按「图片验证码 → 短信验证码」顺序校验。
- 别名：双因素验证、验证码两步验证

### 主题偏好
- 定义：用户级别的界面主题设置，取值为 `dark`（暗黑模式）或 `light`（亮色模式），默认 `dark`；通过 `users.theme_preference` 字段持久化，登录后由前端自动同步。
- 别名：theme_preference、主题设置

### 语言偏好
- 定义：用户级别的语言设置，取值为 `zh` 或 `en`，默认 `zh`；通过 `users.language_preference` 字段持久化，登录后由前端自动恢复上次选择的语言。
- 别名：language_preference、语言设置

### 机票商品
- 定义：商品分类 `category='flight'` 的特殊商品，除基础商品信息外，还在 `flights` 表中维护航班号、出发/落地城市及经纬度、起飞/到达时间、飞行时长、执飞频率、票价与航线坐标（`route_coordinates`）等航班专有字段，通过 `product_id` 关联 `products`。前端点击机票商品时不进入普通详情页，而是跳转 `/flight/:id` 的 FlightDetail 可视化页面。
- 别名：flight、航班、Flight

### 航线飞线图
- 定义：航班频率数据可视化能力。base-app 的 Admin 页面 `FlightMap.vue` 基于 ECharts 飞线图 + 中国地图展示城市间航线频率（接口 `/product/flights/frequency`）；product-app 的 FlightDetail 支持 2D（ECharts）/3D（Cesium）地图切换与飞机飞行路线动画。
- 别名：FlightMap、飞线图
