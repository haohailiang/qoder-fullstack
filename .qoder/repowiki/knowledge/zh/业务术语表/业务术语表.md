### DemoDataInitializer
- 定义：用户服务中的演示数据初始化类，用于在应用启动时向数据库插入 admin、zhangsan、lisi 三个默认用户（密码均为 123456）以及 6 个商品（含 3 个秒杀商品）。

### TrustedAuthenticationFilter
- 定义：业务微服务侧的过滤器，读取网关 `AuthGlobalFilter` 注入的 `X-User-Id` / `X-User-Name` 请求头，将用户信息放入 SecurityContext，使下游服务无需重复校验 JWT。
- 别名：信任认证过滤器

### 秒杀
- 定义：高并发抢购场景：商品服务通过 Redis Lua 脚本原子预扣库存，成功后发送 `SeckillMessage` 到 RabbitMQ，订单服务异步消费创建订单；同时通过 Redis 记录用户已购买标识防止重复购买。
- 别名：seckill、抢购

### 两步验证
- 定义：登录/注册采用的串行验证流程：先提交图片验证码（Base64 PNG + captchaKey），通过后才能获取短信验证码；最终请求体同时携带 `captchaKey`、`captchaValue` 与 `smsCode`，后端按「图片验证码 → 短信验证码」顺序校验。
- 别名：双因素验证、验证码两步验证

### 主题偏好
- 定义：用户级别的界面主题设置，取值为 `dark`（暗黑模式）或 `light`（亮色模式），默认 `dark`；通过 `users.theme_preference` 字段持久化，登录后由前端自动同步。
- 别名：theme_preference、主题设置

### 语言偏好
- 定义：用户级别的语言设置，取值为 `zh` 或 `en`，默认 `zh`；通过 `users.language_preference` 字段持久化，登录后由前端自动恢复上次选择的语言。
- 别名：language_preference、语言设置

### 保险咨询机器人
- 定义：基于 RAG 的商品级问答能力：管理员上传保险条款 PDF → 切分成段并调用 Embedding 写入 Milvus → 用户提问时检索 top-k 片段拼入提示词，由 GLM 流式回答；检索分数低于 `RAG_MIN_SCORE` 时返回拒答文案。
- 别名：insurance-agent、RAG 问答、知识库问答

### 被挤下线（40101）
- 定义：同一账号在新设备登录后，旧 Token 在 Redis 中被覆盖；旧会话再次请求时网关返回 HTTP 401 + 业务码 `40101`，前端据此清理登录态并跳转登录页。
- 别名：Session Invalid、互踢、单设备登录

### 信任头（Trusted Header）
- 定义：网关验签后向内部服务传递的身份头 `X-User-Id` / `X-User-Name` / `X-User-Role`，可附加时间戳与 HMAC 签名的 `X-Gateway-Timestamp` / `X-Gateway-Signature`；下游通过 `TrustedAuthenticationFilter` 直接信任这些头，不再重复解析 JWT。
- 别名：身份透传头、X-User-Id

### 支付宝沙箱支付
- 定义：订单服务对接支付宝开放平台沙箱环境的支付能力：`POST /payments/alipay/{orderNo}` 生成收银台地址，异步通知与主动查询（`sync=true`）双通道回写订单状态；`payment_record` 以 (channel, order_no) 与 trade_no 唯一约束保证幂等。
- 别名：Alipay Sandbox、沙箱支付、异步通知

### 商品图片上传
- 定义：管理员上传商品图片的能力：经商品服务中转校验（魔数 + 5MB + 图片类型）后写入阿里云 OSS；AK/SK 未配置时回退本地磁盘，由 `/api/product/files/local` 静态映射对外提供。
- 别名：OSS 上传、FileStorageServiceRouter、本地兜底存储
