qiankun 2.x 微前端框架；base-app 使用 Vue3 + Element Plus + vue-i18n；product-app 使用 React 18 + Ant Design + react-i18next；order-app 为原生 JS 无框架实现；三者均基于 Vite 5 + TypeScript 构建，并通过 vite-plugin-qiankun 将子应用打包为 qiankun 可加载产物。测试方面：三个子应用均集成 Vitest + jsdom 单元测试，base-app 额外使用 @vue/test-utils，product-app 额外使用 @testing-library/react + @testing-library/user-event；E2E 测试采用 Playwright（位于 frontend/e2e/）；product-app 内置 tracker.ts 埋点工具支持页面访问/商品曝光/交互点击三类事件。
