根目录不承载业务代码，仅作为编排层：docker-compose.yml 将基础设施（mysql、redis、nacos、elasticsearch、rabbitmq）与应用容器（ecommerce-gateway/user/product/order + frontend-base/product-app/order-app）置于同一 compose network，通过 Docker DNS 共享主机名；init-sql/01-init-database.sql 挂载到 /docker-entrypoint-initdb.d 由 MySQL 镜像首次启动自动执行；vm-ssh.js 提供独立于 compose 的远端 VM 部署辅助脚本。backend 与 frontend 之间无直接代码耦合，仅通过网关端口（8080）与 nginx 反向代理进行 HTTP 通信。根 package.json 提供 npm workspaces 统一测试脚本（test:unit / test:e2e / test:all），前端各子应用配置 vitest.config.ts 独立运行单元测试，frontend/e2e/ 目录提供 Playwright E2E 测试套件，后端各服务通过 `mvnw test` 运行 JUnit 5 单元测试。product-app 内置 `src/utils/tracker.ts` 埋点工具，支持页面访问、商品曝光（IntersectionObserver）、交互点击三类事件异步上报。
