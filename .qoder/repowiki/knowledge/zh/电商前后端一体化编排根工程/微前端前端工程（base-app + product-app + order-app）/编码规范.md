- 子应用通过 qiankun props 获取父应用能力（getToken、globalActions、getTheme、getLang），而非直接访问 window 或共享模块。
- 主题与语言偏好统一持久化到 localStorage 的 qoder_theme / qoder_lang 键，并在 base-app 中通过 watch 同步到 qiankun 全局状态，子应用监听 storage 事件或 MutationObserver 响应变化。
- HTTP 请求统一以 `/api` 前缀发起，由 Vite dev server 反向代理到后端网关，避免跨域问题。
- 国际化文案按子应用独立维护（i18n/en.ts、i18n/zh.ts），通过各自的 t/useTranslation 调用，不共享翻译包。
- 登录态只由 `request.ts` 拦截器统一处理：业务码 `40101`（被挤下线/登出）→ `handleKickOut()` 清凭证并 `router.replace('/login')`（不带 redirect）；403 只提示不跳转，避免误退出。
- 可加载等待的交互统一用 `useDelayedLoading` / `useDelayedBusy`（延迟展示，避免闪烁），子应用加载则读取 `subAppLoading` 与 `resetSubAppLoading()`，不要自建 loading 标志。
- 支付、图片上传等异步流程的状态判断必须是终态而不是瞬时文案：轮询上限（2s × 10）后未完成即提示用户稍后在订单详情查看，不以超时当作失败。
