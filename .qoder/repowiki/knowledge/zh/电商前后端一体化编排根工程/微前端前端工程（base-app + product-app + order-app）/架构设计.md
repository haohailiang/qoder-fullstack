本模块由三个独立的 Vite + TypeScript 子项目组成，通过 qiankun 2.x 实现微前端架构：
- base-app（Vue3 + Element Plus + vue-router + vue-i18n）作为主应用，在 `src/micro/index.ts` 中通过 `registerMicroApps` 注册 product-app（`/product`）与 order-app（`/order`），并通过 `initGlobalState` 暴露 token、user、theme、lang 等全局状态；同时通过 `beforeLoad` 注入 React Refresh 兼容桩函数。
- product-app（React 18 + Ant Design + react-router-dom + i18next）使用 `vite-plugin-qiankun` 以 UMD 形式被加载，内部通过 `BrowserRouter basename="/product"` 隔离路由，并监听 localStorage 的 `qoder_theme` / `qoder_lang` 变化同步主题与语言。
- order-app（纯原生 JS，无框架）通过 `OrderApp` 类直接操作 DOM 渲染订单列表与详情，从 props 获取 `getToken` 调用后端 API。
依赖方向单向：base-app 通过 props 向子应用注入 `getToken`、`globalActions`、`getTheme`、`getLang`；子应用之间无相互依赖。所有子应用的 HTTP 请求统一走 `/api` 前缀，由 base-app 的 Vite dev server 代理到后端网关 `http://localhost:8080`。每个子应用独立拥有自己的 Dockerfile，可单独构建部署。

登录后能力（2026-11 新增）：
- 角色分流：`base-app/src/utils/auth.ts` 的 `isAdminUser()`（role === 'ADMIN' 或 username === 'admin'）与 `resolveHomePath()` 决定首页（ADMIN → `/users`，USER → `/product`），受 `meta.adminOnly` 路由守卫兜底。
- 会话保活：`App.vue` 每 30s 调一次 `getCurrentUser()`，并在 `visibilitychange` 时立即补检；`request.ts` 识别到业务码 `40101` 时清登录态并 `router.replace('/login')`（不带 redirect），403 仅提示。
- 统一加载态：`micro/index.ts` 用 `subAppState.pending: Set<string>` + `subAppLoading` 跟踪子应用加载，`beforeLoad`/`beforeMount` 加入、`afterMount`/`afterUnmount` 移除；主应用 `src/composables/useDelayedLoading.ts`、子应用 `src/hooks/useDelayedLoading.ts` 提供延迟展示（避免闪烁）。
- history 保护：`start()` 前用 `protectHistoryState()` 包装 `history.pushState/replaceState`，合并 `{current, back, forward, position}` 状态，避免子路由刷新丢失。
- 业务侧：order-app 新增 `payment.ts`（2s 一轮、最多 10 轮轮询支付状态，支付完成回跳 `/order/pay-result`）与 `loading.ts`；product-app 新增商品图片管理组件与保险咨询抽屉（`react-markdown` 渲染流式回答）。
