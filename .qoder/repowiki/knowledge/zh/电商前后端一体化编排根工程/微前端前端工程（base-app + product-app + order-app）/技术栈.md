qiankun 2.x 微前端框架；base-app 使用 Vue3 + Element Plus + vue-i18n；product-app 使用 React 18 + Ant Design + react-i18next；order-app 为原生 JS 无框架实现；三者均基于 Vite 5 + TypeScript 构建，并通过 vite-plugin-qiankun 将子应用打包为 qiankun 可加载产物。测试侧均为 Vitest（jsdom）+ MSW 模拟接口，E2E 使用 Playwright；子应用额外使用 react-markdown（product-app 保险咨询抽屉）与 axios 封装支付/会话请求。
