三个子应用各自独立运行：`cd frontend/base-app && npm run dev`（默认端口 5173）、`cd frontend/product-app && npm run dev`（默认端口 7100）、`cd frontend/order-app && npm run dev`（默认端口 7200）。开发时需在 base-app 中将 `/api` 代理到后端网关 `http://localhost:8080`。

测试与验收：
- 单测：各子应用 `npm run test`（Vitest + jsdom + MSW），覆盖请求拦截（40101/403）、路由守卫、支付轮询、图片上传组件等。
- E2E：`cd frontend/e2e && npx playwright test`，包含登录、角色分流、商品搜索、下单、支付、加载态与主题同步等场景。
- 依赖服务：保险咨询抽屉与产品页 AI 入口需要先启动 `ai-service`（8084）与 Milvus（19530），否则 `/api/ai/**` 返回 500/502。
