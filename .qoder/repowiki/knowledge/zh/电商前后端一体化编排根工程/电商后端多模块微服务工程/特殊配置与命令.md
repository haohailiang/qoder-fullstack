根目录使用 Maven Wrapper（`mvnw` / `mvnw.cmd`）+ `.mvn/wrapper/maven-wrapper.properties` 管理构建版本；Docker 镜像通过各服务独立的 `Dockerfile.*` 以 `maven:3.9-eclipse-temurin-17` 为 builder 阶段执行 `mvn dependency:go-offline -pl <module> -am -B` 后再 `mvn package -DskipTests`，运行阶段使用 `eclipse-temurin:17-jre-alpine`。

本地单服务调试可用 `backend/run-product.ps1`、`run-order.ps1`（及 `start-order.bat`）。新增功能相关开关与凭据：
- 网关：`gateway.session-check.enabled=true` 控制 Redis 会话比对，`security.trusted-header.verify-signature`（默认 false）与 `max-age-seconds:300` 控制下游对身份头签名的校验。
- 订单服务：`ALIPAY_APP_ID` / `ALIPAY_PRIVATE_KEY` / `ALIPAY_PUBLIC_KEY` / `ALIPAY_GATEWAY_URL` / `ALIPAY_NOTIFY_URL` / `ALIPAY_RETURN_URL` / `ALIPAY_TIMEOUT_EXPRESS`；三项凭据缺失时创建支付返回 503。
- 商品服务：`OSS_ACCESS_KEY_ID` / `OSS_ACCESS_KEY_SECRET` / `OSS_BUCKET` / `OSS_ENDPOINT` / `OSS_DIR`；AK/SK 未配置时自动回退到本地 `uploads` 目录（对外前缀 `/api/product/files/local`）。
