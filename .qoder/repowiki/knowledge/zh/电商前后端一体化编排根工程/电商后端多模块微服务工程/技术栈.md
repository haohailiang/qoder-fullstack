Spring Boot 3.3.5 + Spring Cloud 2023.0.3 + Spring Cloud Alibaba 2023.0.1.2（Nacos 作为注册中心/配置中心）；JJWT 0.11.5 用于 HS256 签名；Spring Data Redis + Lua 脚本实现秒杀库存原子扣减；RabbitMQ 承载秒杀订单异步队列；Elasticsearch 提供商品检索；MyBatis + MySQL 持久化；SpringDoc OpenAPI 生成 Swagger UI。订单服务集成支付宝沙箱 SDK（RSA2 签名、异步通知验签）；商品服务集成阿里云 OSS SDK（同时内置本地磁盘存储实现作为兜底）；网关额外引入 `spring-boot-starter-data-redis-reactive` 做会话比对，并用 HMAC 对信任头签名。
