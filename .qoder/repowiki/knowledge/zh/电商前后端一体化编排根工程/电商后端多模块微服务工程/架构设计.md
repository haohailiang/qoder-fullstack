Maven 多模块聚合工程（根 `pom.xml` packaging=pom），通过 `dependencyManagement` 统一管理 Spring Cloud BOM、Spring Cloud Alibaba BOM 以及内部 `ecommerce-common` 依赖版本。

- `ecommerce-common`：纯公共依赖模块，定义跨服务契约 `Result<T>`、全局异常处理器 `GlobalExceptionHandler`、业务异常 `BusinessException`、统一消息体 `SeckillMessage` 以及 RabbitMQ/Security 共享配置。
- `ecommerce-gateway`：无状态网关入口，`AuthGlobalFilter` 在入口处用 JJWT HS256 校验 JWT，白名单放行登录/注册/验证码/Swagger，鉴权后将 `X-User-Id`、`X-User-Name` 注入下游请求头。后续又补充了单设备会话比对（读 Redis `login:token:{userId}`，不一致返回 401 + 业务码 40101）、角色头 `X-User-Role` 与 `X-Gateway-Signature` HMAC 签名，并将 ai-service 以固定 `uri` 纳入路由。
- `ecommerce-user`：用户认证与短信服务，Spring Security + JJWT 签发 Token，Redis 做会话存储，含 controller/service/repository/entity 完整分层及单元测试。
- `ecommerce-product`：商品与库存服务，MyBatis + MySQL 持久化，Elasticsearch（`ProductDocument` + `ProductElasticsearchRepository`）做检索，Redis + Lua 脚本（`lua/seckill_stock.lua`）实现原子预扣减库存；另外提供 `POST /files/images` 图片上传（`FileStorageServiceRouter` 按 `OssProperties.isConfigured()` 在 OSS 与本地磁盘间切换）与 `PUT /products/{id}/image` 图片绑定。
- `ecommerce-order`：订单服务，通过 Feign `ProductClient` 调用商品服务，监听 RabbitMQ 队列 `SECKILL_QUEUE` 异步创建订单；并实现支付宝沙箱支付（`POST /payments/alipay/{orderNo}` 下单、`GET /payments/alipay/{orderNo}/status` 查询、`POST /payments/alipay/notify` 异步通知）与 `payment_record` 条件更新幂等。

依赖方向：gateway → user/product/order；order → product（Feign）；user/product/order 均依赖 common。各服务通过 `bootstrap.yml` + Nacos 进行配置发现，数据库初始化 SQL 位于各自 `resources/db/schema.sql`，MyBatis Mapper XML 置于 `resources/mapper/`。每个服务均有独立 Dockerfile（`Dockerfile.user|product|order|gateway`）。

边界：保险咨询机器人不在本 Maven 工程内，而是独立的 Python `ai-service`（FastAPI，8084），仅通过网关 `/api/ai/**` 与 Java 侧交互，不共享 `ecommerce-common` 契约（错误体、鉴权实现均各自一套）。
