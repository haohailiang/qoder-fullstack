根目录不承载业务代码，仅作为编排层：docker-compose.yml 将基础设施（mysql、redis、nacos、elasticsearch、rabbitmq）与应用容器（ecommerce-gateway/user/product/order + frontend-base/product-app/order-app）置于同一 compose network，通过 Docker DNS 共享主机名；init-sql/01-init-database.sql 挂载到 /docker-entrypoint-initdb.d 由 MySQL 镜像首次启动自动执行；vm-ssh.js 提供独立于 compose 的远端 VM 部署辅助脚本。backend 与 frontend 之间无直接代码耦合，仅通过网关端口（8080）与 nginx 反向代理进行 HTTP 通信。

此外，根目录还容纳一个异构服务 `ai-service/`（Python FastAPI，端口 8084）：不在主 compose 内、不注册 Nacos，由网关以固定 `uri: http://localhost:8084` + `Path=/api/ai/**` + `StripPrefix=2` 代理；其向量库 Milvus 由独立的 `docker-compose.milvus.yml` 编排（默认端口 19530），因此容器内的 Spring Cloud Gateway 无法再用 `localhost` 访问 ai-service，需要改为 `host.docker.internal:8084`。`init-sql/` 下除 `01-init-database.sql` 外，还有 `02-alipay-payment.sql`（支付记录表）与 `03-insurance-agent.sql`（保险文档 `ai_insurance_document`、会话 `ai_chat_session`、消息 `ai_chat_message` 三张表），同样由 MySQL 首次启动自动执行。
