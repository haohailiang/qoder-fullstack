使用 `docker compose up --build` 一次性拉起全部中间件、后端四服务与前端三容器；MySQL 首次启动会自动执行 init-sql/01-init-database.sql 完成建库与演示数据注入。

新增能力对应的独立命令：
- 向量库：`docker compose -f docker-compose.milvus.yml up -d`（etcd + MinIO + Milvus v2.4.15，暴露 19530/9091）。
- AI 服务：`ai-service/run.ps1` 启动 FastAPI（端口 8084），不进入主 compose，需自行保证 Milvus 与 `.env` 中的智谱/百炼密钥已就绪。
- 数据库增量：`init-sql/02-alipay-payment.sql`（payment_record）与 `init-sql/03-insurance-agent.sql`（ai_insurance_document / ai_chat_session / ai_chat_message）仅在 MySQL 数据卷首次初始化时自动执行，已有库需手动导入。
- 密钥注入：支付宝（ALIPAY_APP_ID / PRIVATE_KEY / PUBLIC_KEY / NOTIFY_URL / RETURN_URL / TIMEOUT_EXPRESS）与阿里云 OSS（OSS_ACCESS_KEY_ID / ACCESS_KEY_SECRET / BUCKET / ENDPOINT）均通过环境变量传入，不得写入仓库。
