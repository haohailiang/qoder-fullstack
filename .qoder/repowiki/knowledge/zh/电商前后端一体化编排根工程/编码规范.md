- 后端服务通过环境变量 SPRING_PROFILES_ACTIVE=docker 切换至 Docker 运行配置，并在 compose 中以 service_name 形式引用 mysql/redis/nacos/rabbitmq/elasticsearch 主机名。
- 所有 MySQL 连接 URL 统一携带 useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true 参数。
- 数据库表统一采用 utf8mb4 + utf8mb4_unicode_ci 字符集，并包含 created_by/created_date/last_modified_by/last_modified_date 审计字段。
- 敏感凭据（支付宝 APP_ID/私钥/公钥、OSS AK/SK、智谱与百炼 API Key）一律通过环境变量或仓库根 `.env` 注入，compose 中以 `${VAR:-}` 形式透传；配置项默认空值，未配置时服务照常启动，仅在调用相关接口时返回业务码 503。
- 异构服务的运行方式不纳入主 compose：Milvus 只与 ai-service 一同在独立 compose 中编排，ai-service 以宿主机进程运行（8084），容器化时需把网关路由改为 `host.docker.internal:8084`。
